# Port-Truck-Scheduling-
Data for research study port truck scheduling 

This repository provides the input data and numerical settings for a truck-scheduling model on a simplified Halifax-inspired road network with two ports and a shared inland destination.

Files
- Network data (.xlsx): Road connectivity, baseline travel times, node coordinates, and urban road links.
- Numerical parameters (.txt): Cargo releases, truck fleets, loading capacities, scheduling horizon, peak-hour travel conditions, operating costs, and optimization settings.
